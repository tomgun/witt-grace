## [Unreleased]

### Added
- WG-006: the nine-language catalog. `locales/messages.psv` is the prototype's table (866 keys); `npm run i18n` (`scripts/generate-locales.ts`) renders the typed `src/lib/i18n/catalog.ts` (`MessageKey`, `Language`); `src/lib/i18n/i18n.ts` gives `translate(language, key, params)` and a bound `translator`. Tests pin that the committed catalog equals the rendered table, that every key is non-empty and not raw in all nine languages, that `{placeholders}` agree across languages, and the Finnish glossary words.
- WG-005: `src/domain/serialize.ts` — the `.witt.json` file form (`JSON.stringify(validated, null, 2) + '\n'`), byte-identical to the prototype's export for every example and stable under a second round-trip; the compact storage form; the export filename slug (pinned to the prototype's NFKD quirk).
- WG-004: every document change is a serializable `Command` (46 types) applied by `applyCommand(project, command, { now, actorId })` in `src/domain/commands.ts`: pure, ids supplied by the caller so a peer can replay the same log, the input never mutated, refusals with the prototype's messages, `lastEditedBy` and `createdBy` tagged and the result re-validated like the prototype's mutation wrapper. `src/domain/project.ts` creates blank documents and tidy-tree layouts; `src/domain/views.ts` holds the view-only projections (visible nodes, focus highlighting that respects explicit collapses, option group path, guided review order, value profile, evidence-overlap note). `tests/unit/commands.test.ts` replays 60 edits through the prototype engine and through the commands with identical ids and clock and asserts identical documents after every step.
- WG-003: `src/domain` in TypeScript — the v8 model and closed sets (`model.ts`), the parser as the single trust boundary (`parse.ts`, the prototype's Finnish refusal messages kept), the `evidence-v3-links` engine for the collective viewpoints and per person (`scoring.ts`, with marginal effects), review readers (`reviews.ts`), feasibility (`eligibility.ts`), ballot preferences (`ballots.ts`) and rankings (`ranking.ts`). Pure by construction: no DOM, storage, clock or randomness; imports only inside the folder (ESLint and `tests/unit/import-direction.test.ts`). Tooling: TypeScript 5.9 strict with Node's native type stripping (Node 24; `.nvmrc`), ESLint 9 + typescript-eslint, Prettier, `node --test`. `npm run check` now runs docs, spec lock, lint, typecheck, format and tests.
- WG-002: golden fixtures generated from the frozen prototype engine (`scripts/golden-from-proto.mjs`, `npm run golden`): every v8 example plus 20 hand-built cases (the G-02 table, four levels with sign reversal, a creation stance overridden by a rating, a missing review, a stale fingerprint, a thesis with its own vote, equal vs shares, a zero-share user and an AI profile, structural preview, gates and values, option groups, a reason concept in two contexts, a locked shared reason, a secondary link with a route note, ballot rounds with shares). `tests/golden/golden.test.ts` asserts the new domain reproduces every number exactly: 229 golden assertions green on the first run.
- WG-001 repository baseline (2026-11-08). The GPT-era prototype `0.11.0-dev.32` moved to `witt-grace-gpt-proto/` and frozen as the reference (372 tests, build and Pages preflight verified, standalone SHA-256 `8867de17…`). The product specs lifted into `docs/spec/` with a change policy and changelog. Quality system copied from `price-alert-platform` and `agentic-af-for-claude`: `docs/principles/`, `docs/lenses/` with WITT project specifics, `.claude/` hooks (protect files, guard bash) and skills (`/dev`, `/feature`, `/verify`, `/review`). Checks: `scripts/check-docs.mjs` (local links, spec index, lens placeholders) and `scripts/check-spec-lock.mjs` (a spec change needs a changelog line). CI with `checks` and `prototype` jobs; Pages workflow publishing the prototype at `/proto/`. Docs: README, CONTRIBUTING, STATUS, ARCHITECTURE (proposed target), TESTING, ADRS (A001–A009), ISSUE-PLAN (WG-001…WG-020), PROTOTYPE_REFERENCE.
