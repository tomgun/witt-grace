# The dev32 prototype as reference implementation

`witt-grace-gpt-proto/` is the WITT `0.11.0-dev.32` prototype that was developed with ChatGPT before this repository existed. It is **frozen**: a working reference, a behavior oracle, and a UI benchmark for the new implementation that is being built at the repository root. It is not the codebase being evolved.

## What it is

| Item | Value |
| --- | --- |
| Release | `0.11.0-dev.32`, document schema v8, scoring `evidence-v3-links` |
| Runtime | Plain JavaScript, no dependencies, no backend. `index.html` + `src/*.js` + `locales/` |
| Size | `src/app.js` 4 333 lines (UI orchestration monolith), `src/core.js` 1 527 lines (pure domain + scoring, no DOM) |
| Tests | 372 Node tests (`npm run check`), 13 Python Playwright browser smokes (`tools/smoke-*.py`) |
| Build | `npm run build` → `dist/index.html` + `dist/witt-standalone.html`; standalone SHA-256 `8867de17dee1f01f97341548d298a706260e4a26c5104fc728dd6af2bad98ec8` |
| Verified | 2026-11-08 in this repository: check 372/372, build OK, Pages preflight PASS, SHA matches |
| Languages | 9 locales in `locales/messages.psv` (fi, de, en, es, fr, ru, zh-Hans, ja, ko) |
| Docs | Its own `CLAUDE.md`, `docs/` and `handoff/` describe the prototype and the GPT-era handoff plan. The product specs were lifted to `../docs/spec/`; the rest stays as prototype history. |

## Run it

```sh
cd witt-grace-gpt-proto
npm run check        # 372 Node tests, locale and schema generation, doc link checks
npm run build        # static site in dist/
npm run dev          # local static server; open the printed URL
```

Open `dist/witt-standalone.html` directly in a browser for a one-file offline version. Browser tests need Python 3, `pip install playwright==1.57.0` and a Chromium.

Its GitHub workflows live under `witt-grace-gpt-proto/.github/` and are therefore inactive. The root CI will build the prototype and publish it under a `/proto/` path on GitHub Pages so it stays reachable in a browser.

## How the new implementation uses it

1. **Scoring oracle.** `src/core.js` is callable from Node without a DOM (`require('./src/core.js')` exposes `WittCore`). Golden fixtures for the new engine are generated by running the prototype engine on `examples/*.witt.json` and on hand-built cases, and the new engine must reproduce every internal `I`, visible balance `S`, eligibility and aggregation value exactly.
2. **Format oracle.** `schemas/project.v8.schema.json` and `src/import-validation.js` define what a valid `.witt.json` is. The new implementation reads and writes v8 unchanged until a deliberate version bump.
3. **UX benchmark.** The refined UI in `index.html` + `src/app.js` + `src/styles.css` is what `docs/spec/UX_AND_WORKFLOWS.md` describes. Compare the new UI against it side by side at 1440×900 and 390×844.
4. **Translation source.** `locales/messages.psv` is the starting catalog for the new app's 9 languages.
5. **Test ideas, not test code.** The 372 tests show which behaviors mattered. Port the intent as proper unit tests against the new modules; do not copy tests that grep HTML or JS source text.

## What not to carry over

- The monolithic `src/app.js` structure and global `window` wiring.
- The `tests/*.test.cjs` files that assert on HTML or source strings instead of behavior.
- The GPT-era process documents (`CONTINUE-HERE.md`, `TASKS.md`, `DEVELOPMENT-STATUS.md`, `handoff/`). They describe a plan to refactor the prototype in place, which the owner replaced on 2026-11-08 with a rebuild on a better foundation.

## Freeze rules

- No edits inside `witt-grace-gpt-proto/` except to keep it runnable (for example a path fix for the root CI). Every such edit is noted in `docs/spec/CHANGELOG.md`.
- It must keep passing its own `npm run check` and `npm run build`.
- `witt-grace-gpt-proto/dist/` is build output and is not committed.
