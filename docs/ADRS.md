# Architecture decision records (ADR)

Started 2026-11-08. One table, one row per decision; the prototype handoff's "ADR" mentions are history. Rows marked *(proposed)* wait for the owner's confirmation; *(open)* rows name the options and the trigger for deciding. A new runtime dependency or a reversed boundary needs a row here (CLAUDE.md).

| ADR | Decision | Why | When to re-open |
| --- | --- | --- | --- |
| A001 | Rebuild from scratch; the dev32 prototype is frozen in `witt-grace-gpt-proto/`, runnable, published at `/proto/`, and used as the scoring, format and UX oracle (owner decision 2026-11-08; supersedes the handoff's in-place refactor roadmap) | The prototype's UI is good and its engine is tested, but its code (a 4 333-line DOM monolith, tests that grep source text) is not a foundation; a rebuild under golden fixtures keeps the behaviour and replaces the structure | Never for the oracle role; the prototype is deleted only after the new app passes every golden fixture and every UX item in `docs/spec/REQUIREMENTS.md` |
| A002 *(proposed)* | TypeScript strict on Node 24 LTS with native type stripping for domain, scripts and tests (`erasableSyntaxOnly`, `verbatimModuleSyntax`, `noUncheckedIndexedAccess`, relative `.ts` imports); `node --test`; ESLint + Prettier; no bundler until the UI needs one | One runtime for tests, scripts and tooling; the owner's other project proved the setup; the domain stays runnable without a build | A non-erasable TypeScript feature becomes necessary; the UI choice (A005) brings its own toolchain |
| A003 *(proposed)* | Dependency direction `src/domain` (pure, builtins only) ← `src/lib` ← `src/app`, enforced by ESLint and an import-direction test; closed sets owned by one module each; parse once at the boundary | The prototype's audit named exactly this as the missing boundary; it is what makes the golden fixtures runnable without a browser | Never casually; a cycle or a reversed arrow is an ADR |
| A004 | Document format `schemaVersion: 8` and scoring `evidence-v3-links` preserved exactly; the prototype's `schemas/project.v8.schema.json` is copied and asserted equal; golden fixtures generated from the prototype engine are the numeric contract | People's existing `.witt.json` files keep working; the method's numbers are the product | A deliberate v9 or a new scoring identifier, each with a migration function, before/after fixtures and a `docs/spec/CHANGELOG.md` line |
| A005 *(open)* | UI technology: (a) TypeScript + vanilla DOM with a small view-model layer, (b) a component framework (Preact/React/Svelte) with Vite. Decide after WG-003 is green, with the Bitberg theme, four-pane docking, keyboard camera, large-tree SVG rendering and single-file offline export as the evaluation cases | The handoff forbids a framework by default; the choice must be made against the refined UX, not in the abstract | Decided at WG-007; re-opened only if the chosen option fails one of the evaluation cases |
| A006 *(proposed)* | Static hosting on GitHub Pages from `main` by workflow: the prototype under `/proto/`, the new app under `/`; one-file offline standalone kept as a download | Local-first, no backend; the prototype is reachable in a browser as the owner asked | A custom domain for private use (storage-origin isolation, `docs/spec/SECURITY_AND_PRIVACY.md`) |
| A007 | Spec lock (owner request 2026-11-08): `docs/spec/**` changes only with a line in `docs/spec/CHANGELOG.md` in the same change; a Claude hook refuses the edit otherwise and CI refuses the PR; requirement IDs are permanent; numbers are pinned by tests | Specs must not drift by accident while the code is rebuilt; the mechanism is one hook and one 40-line script, not a process | If the hook produces false refusals in practice (then the rule moves to CI only) |
| A008 | Language: English code, docs and commits; Finnish-first UI with nine locales from one catalog and a coverage test that fails on a missing or raw key; the prototype's vocabulary is the glossary | The owner reads Finnish UI with ä/ö; the nine locales exist and must not rot | A tenth language; a vocabulary change (then the glossary in `docs/ARCHITECTURE.md` changes first) |
| A009 *(proposed)* | Browser tests with Playwright, Chromium only, keyboard first, from WG-009; the prototype's Python smokes stay with the prototype | Rendering, focus order and the magic of the dock cannot be asserted from Node; Chromium is what the prototype was verified on | Safari or Firefox parity becomes a requirement |
