# WITT example files — native v8

The current native WITT format is **schema v8**, scoring **`evidence-v3-links`**. All `*.witt.json` examples in this directory are intended for this version, including examples with filenames containing older dev numbers (those names record when a regression originated). `ai-draft-with-ratings-dev14.witt.json` is an AI-draft-format example, **not** a native project.

Older v1/v2/v4 sample documents have been removed from the active repository and preserved in the optional historical archive; do not import them as current v8 projects.

Built-in demonstration content is public when WITT is deployed to GitHub Pages, since `src/examples.js` bundles it. Before deployment review examples for any private material. The examples are illustrative and not expert/medical advice or genuine poll results.

`npm run examples` regenerates the `src/examples.js` asset from source examples. Do not edit the generated copy manually.
