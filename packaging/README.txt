SUOMEKSI
--------
Tämä paketti on WITT-työkalu yhtenä tiedostona. Se toimii omalla koneellasi
ilman WITTin verkkosivua, vaikka sivusto katoaisi verkosta.

Käyttö
  1. Pura paketti kansioon, jossa aiot sitä pitää.
  2. Avaa witt.html selaimessa (kaksoisnapsautus). Ajantasainen Chrome, Edge,
     Firefox tai Safari.
  Mitään ei asenneta, eikä työkalu lähetä tietojasi minnekään.

Työn tallentaminen
  - Tallenna työsi tiedostoksi: Tiedosto → Tallenna tiedosto. Tiedosto on
    varmin tallennuspaikka.
  - Selain tallentaa keskeneräisen työn ja asiakirjakirjaston myös omaan
    muistiinsa. Se muisti on sidottu selaimeen ja voi olla sidottu myös
    tiedoston sijaintiin: jos siirrät tai nimeät witt.html:n uudelleen, vaihdat
    selainta tai tyhjennät selaimen tiedot, selaimeen tallennettu työ voi
    kadota. Ota kirjastosta varmuuskopio ennen siirtoa.

Mikä toimii eri tavalla kuin verkkosivulla
  - Yhteistyö (Työskentele yhdessä) tarvitsee verkkoyhteyden, eikä sen
    toimivuutta levyltä avatusta tiedostosta ole taattu kaikissa selaimissa
    ja verkoissa. Oletuksena yhteys välitetään julkisten Nostr-välittäjien
    kautta. Oman välityspalvelimen saa käyttöön näin: Työskentele yhdessä →
    Yhteyden välittäjä → Oma välityspalvelin (wss://-osoite) → kirjoita
    palvelimesi osoite, esimerkiksi wss://relay.example.org. Osoitteen pitää
    alkaa wss://. Kaikkien osallistujien pitää päästä samaan osoitteeseen.
    Välityspalvelinohjelma ei ole tässä paketissa.
  - "Kopioi linkki asiakirjaan" ja tekoälyn "lyhyt pyyntö" puuttuvat, koska
    levyllä olevalla tiedostolla ei ole osoitetta, jonka muut voisivat avata.
    Tekoälytehtävän kopiointi ja vastauksen tuonti toimivat.

Päivitykset
  Uusi versio on uusi tiedosto. Tallenna työsi tiedostoiksi ja avaa ne uudessa
  versiossa.

IN ENGLISH
----------
This package is the WITT tool as a single file. It runs on your own computer
without WITT's website, even if the site disappears from the web.

Use
  1. Unpack the package into the folder where you will keep it.
  2. Open witt.html in a browser (double-click). A current Chrome, Edge,
     Firefox or Safari.
  Nothing is installed, and the tool sends your data nowhere.

Saving your work
  - Save your work as a file: Tiedosto (File) → Tallenna tiedosto (Save file).
    A file is the safest place.
  - The browser also keeps unfinished work and the document library in its own
    storage. That storage belongs to the browser and may be tied to the file's
    location: if you move or rename witt.html, change browsers or clear the
    browser's data, work saved in the browser can be lost. Back up the library
    before moving.

What works differently from the website
  - Collaboration (Työskentele yhdessä) needs a network connection, and it is
    not guaranteed to work from a file opened from disk in every browser and
    network. By default the connection is relayed through public Nostr relays.
    To use your own relay: Työskentele yhdessä → Yhteyden välittäjä (Connection
    relay) → Oma välityspalvelin (Your own relay, wss:// address) → enter your
    server's address, for example wss://relay.example.org. The address must
    start with wss://. Every participant must be able to reach it. The relay
    program is not in this package.
  - "Copy a link to the document" and the AI "short request" are absent,
    because a file on a disk has no address others could open. Copying the AI
    task and importing the reply work.

Updates
  A new version is a new file. Save your work as files and open them in the
  new version.
